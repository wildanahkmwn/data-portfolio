# Projects

Self-contained portfolio demos. Each folder should include:

- `README.md` with quick start
- runnable code / SQL
- `docs/case_study.md`
- at least one screenshot under `docs/screenshots/`

## Current

- `agronomy-marketplace-analytics/` — Postgres to ClickHouse pipeline, analyst insights, GMV forecast / reactivation

## Template

```text
projects/<short-name>/
  README.md
  requirements.txt
  docker-compose.yml
  docs/
    case_study.md
    screenshots/
  app/ or src/
  sql/
```
